\section{FraudPipeline Workflow}

Listing~\ref{lst:wf-fraudpipeline-full} is the workflow of Section~\ref{sec:developer-workflow}: an
internal call (Listing~\ref{lst:call-step-internal}) followed by an external one
(Listing~\ref{lst:wf-external-part}).

\begin{lstlisting}[language=Kotlin,caption={FraudPipeline workflow: one call resolved through the registry and one with a literal endpoint.},label={lst:wf-fraudpipeline-full},basicstyle=\ttfamily\small,breaklines=false]
val wf = workflow {
  name("FraudPipeline")
  description("Fraud check followed by a partner risk score")
  params("args")
  steps(
    step {
      name("fraud-check")
      description("Call the fraud-check function")
      context(call {
        method(GET)
        internalFunction("fraud-check", "./deploy/fraud-check.json")
        result("fraudResult")
      })
    },
    step {
      name("external-risk-api")
      description("Call the partner risk-scoring API")
      context(call {
        method(POST)
        host("api.partner.example")
        path("/v1/risk-score")
        result("riskResult")
      })
    }
  )
  result("riskResult")
}
\end{lstlisting}

\section{PaymentAuthorization Workflow}

Listing~\ref{lst:case-payment-workflow} is the case-study workflow of
Section~\ref{sec:case-design}.

\begin{lstlisting}[language=Kotlin,caption={PaymentAuthorization workflow: two internal scoring calls feeding a decision.},label={lst:case-payment-workflow},basicstyle=\ttfamily\small,breaklines=false]
val PaymentAuthorization = workflow {
  name("PaymentAuthorization")
  description(
    "Real-time fraud screening for card payment authorization")
  params("transaction")
  steps(
    step {
      name("fraud-check")
      description("Flag transactions that match known fraud patterns")
      context(call {
        method(POST)
        internalFunction("fraud-check", "./deploy/fraud-check.json")
        query("amount" to variable("transaction.amount"),
          "country" to variable("transaction.country"))
        result("fraudResult")
      })
    },
    step {
      name("risk-score")
      description("Score the transaction from its features")
      context(call {
        method(POST)
        internalFunction("risk-score", "./deploy/risk-score.json")
        query("amount" to variable("transaction.amount"))
        result("riskResult")
      })
    },
    step {
      name("decision")
      description("Decline flagged or high-risk transactions")
      context(switch {
        conditions(
          condition {
            match(variable("fraudResult").withKey("flagged")
              equalTo value(true))
            jump("decline-transaction")
          },
          condition {
            match(variable("riskResult").withKey("score")
              greaterThan value(75))
            jump("decline-transaction")
          }
        )
        default("approve-transaction")
      })
    },
    step {
      name("approve-transaction")
      description("Record the approval")
      context(assign {
        variables(variable("decision") equalTo value("approved"))
      })
      next("report-decision")
    },
    step {
      name("decline-transaction")
      description("Record the decline")
      context(assign {
        variables(variable("decision") equalTo value("declined"))
      })
    },
    step {
      name("report-decision")
      description("Report the decision to core banking")
      context(call {
        method(POST)
        host("core-banking.internal.example")
        path("/v1/authorisations")
        body(variable("transaction"))
        query("decision" to variable("decision"))
        result("coreBankingResult")
      })
    }
  )
  result("decision")
}
\end{lstlisting}

\section{Case-Study Functions and Rendered Workflows}
\label{app:case-code}

This section gives the code of the case-study functions on each provider, the workflow definitions
OmniFlow rendered from Listing~\ref{lst:case-payment-workflow}, and the inputs of the executions
(Section~\ref{sec:case-artifacts}). The files are in the repository folders
\texttt{case-study-gcp} and \texttt{case-study-aws}.

\subsection{Functions on GCP}

On GCP, each function is a QuickFaaS hook that takes an \texttt{HttpRequestQf} and an
\texttt{HttpResponseQf} (Listings~\ref{lst:case-gcp-fraud}--\ref{lst:case-gcp-stub}). The stub
parses the body itself, because QuickFaaS's JSON helper rejects the content type Cloud Workflows
sends (Section~\ref{sec:case-discussion}).

\begin{lstlisting}[language=Java,caption={\texttt{fraud-check} on GCP.},label={lst:case-gcp-fraud},basicstyle=\ttfamily\fontsize{7.2}{8.6}\selectfont,breaklines=true]
import quickfaas.triggers.http.HttpRequestQf;
import quickfaas.triggers.http.HttpResponseQf;

// Flags a transaction as suspicious when it is a high-value payment made abroad.
public class MyFunctionClass {
    public void myFunction(HttpRequestQf req, HttpResponseQf res) {
        double amount = Double.parseDouble(req.getQueryParameter("amount"));
        String country = req.getQueryParameter("country");
        boolean flagged = amount > 1000 && !"PT".equals(country);
        res.setContentType("application/json");
        res.send(200, "{\"flagged\": " + flagged + "}");
    }
}
\end{lstlisting}

\begin{lstlisting}[language=Java,caption={\texttt{risk-score} on GCP.},label={lst:case-gcp-risk},basicstyle=\ttfamily\fontsize{7.2}{8.6}\selectfont,breaklines=true]
import quickfaas.triggers.http.HttpRequestQf;
import quickfaas.triggers.http.HttpResponseQf;

// Scores a transaction from 0 to 100, growing with its amount.
public class MyFunctionClass {
    public void myFunction(HttpRequestQf req, HttpResponseQf res) {
        double amount = Double.parseDouble(req.getQueryParameter("amount"));
        long score = Math.min(100, Math.round(amount / 50));
        res.setContentType("application/json");
        res.send(200, "{\"score\": " + score + "}");
    }
}
\end{lstlisting}

\begin{lstlisting}[language=Java,caption={Core banking stub on GCP.},label={lst:case-gcp-stub},basicstyle=\ttfamily\fontsize{7.2}{8.6}\selectfont,breaklines=true]
import com.google.gson.JsonParser;
import quickfaas.triggers.http.HttpRequestQf;
import quickfaas.triggers.http.HttpResponseQf;

// Stand-in for the core banking system: acknowledges the decision it receives.
// Parses the body itself: getFromJsonBody rejects Cloud Workflows' 'application/json; charset=utf-8'.
public class MyFunctionClass {
    public void myFunction(HttpRequestQf req, HttpResponseQf res) {
        String decision = req.getQueryParameter("decision");
        String id = JsonParser.parseString(req.getBody()).getAsJsonObject().get("id").getAsString();
        res.setContentType("application/json");
        res.send(200, "{\"recorded\": true, \"id\": \"" + id + "\", \"decision\": \"" + decision + "\"}");
    }
}
\end{lstlisting}

\subsection{Functions on AWS}

On AWS the QuickFaaS Lambda template passes the query parameters as a map and returns what the
function returns (Listings~\ref{lst:case-aws-fraud} and~\ref{lst:case-aws-risk}), so the scoring
logic is the same as on GCP but written against another signature. The stub is a Python Lambda
function behind an API Gateway HTTP API, created with the AWS CLI rather than QuickFaaS, because it
must read the transaction from the request body (Listing~\ref{lst:case-aws-stub}).

\begin{lstlisting}[language=Java,caption={\texttt{fraud-check} on AWS.},label={lst:case-aws-fraud},basicstyle=\ttfamily\fontsize{7.2}{8.6}\selectfont,breaklines=true]
import com.amazonaws.services.lambda.runtime.Context;
import java.util.Map;

// Flags a transaction as suspicious when it is a high-value payment made abroad.
public class MyFunctionClass {
    public Map<String, Object> handleRequest(Map<String, String> query, Context context) {
        double amount = Double.parseDouble(query.get("amount"));
        String country = query.get("country");
        return Map.of("flagged", amount > 1000 && !"PT".equals(country));
    }
}
\end{lstlisting}

\begin{lstlisting}[language=Java,caption={\texttt{risk-score} on AWS.},label={lst:case-aws-risk},basicstyle=\ttfamily\fontsize{7.2}{8.6}\selectfont,breaklines=true]
import com.amazonaws.services.lambda.runtime.Context;
import java.util.Map;

// Scores a transaction from 0 to 100, growing with its amount.
public class MyFunctionClass {
    public Map<String, Object> handleRequest(Map<String, String> query, Context context) {
        double amount = Double.parseDouble(query.get("amount"));
        return Map.of("score", Math.min(100, Math.round(amount / 50)));
    }
}
\end{lstlisting}

\begin{lstlisting}[language=Python,caption={Core banking stub on AWS (Python, behind API Gateway).},label={lst:case-aws-stub},basicstyle=\ttfamily\fontsize{7.2}{8.6}\selectfont,breaklines=true]
import base64
import json


# Stand-in for the core banking system, behind an API Gateway HTTP API: acknowledges the decision
# (query parameter) for the transaction it receives as the JSON body.
def handler(event, context):
    body = event.get("body") or "{}"
    if event.get("isBase64Encoded"):
        body = base64.b64decode(body).decode()
    transaction = json.loads(body)
    decision = (event.get("queryStringParameters") or {}).get("decision")
    return {
        "statusCode": 200,
        "headers": {"Content-Type": "application/json"},
        "body": json.dumps({"recorded": True, "id": transaction.get("id"), "decision": decision}),
    }
\end{lstlisting}

\subsection{Rendered Workflow Definitions}

Listing~\ref{lst:case-rendered-gcp} is the Cloud Workflows definition (YAML) deployed to GCP, and
Listing~\ref{lst:case-rendered-aws} the Step Functions state machine (Amazon States Language,
JSON) deployed to AWS. Both come from the same workflow definition; only the resolved endpoints and
the provider's syntax differ.

\begin{lstlisting}[language={},caption={Cloud Workflows definition rendered for GCP (YAML).},label={lst:case-rendered-gcp},basicstyle=\ttfamily\fontsize{7.2}{8.6}\selectfont,breaklines=true]
main:
    params: [ transaction ]
    steps:
        - fraud-check:
            call: http.post
            args:
                url: https://fraud-check-jllpr4krfq-ew.a.run.app
                query:
                    amount: ${transaction.amount}
                    country: ${transaction.country}
            result: fraudResult
        - risk-score:
            call: http.post
            args:
                url: https://risk-score-jllpr4krfq-ew.a.run.app
                query:
                    amount: ${transaction.amount}
            result: riskResult
        - decision:
            switch:
                - condition:
                    ${fraudResult.body.flagged == true}
                  next: decline-transaction
                - condition:
                    ${riskResult.body.score > 75}
                  next: decline-transaction
            next: approve-transaction
        - approve-transaction:
            next: report-decision
            assign:
                - decision: 'approved'
        - decline-transaction:
            assign:
                - decision: 'declined'
        - report-decision:
            call: http.post
            args:
                url: https://core-banking-stub-jllpr4krfq-ew.a.run.app/
                query:
                    decision: ${decision}
                body: ${transaction}
            result: coreBankingResult
        - return_output:
            return: ${decision}
\end{lstlisting}
